## 常见问题

**RSS 是什么？** 一种网站更新通知格式。将订阅地址加入阅读器后，新内容自动送达。

**更新频率？** 不定期。仅在产生值得记录的进展时更新。

**能否在网页留言？** 可以。评论区位于每篇档案底部，由 GitHub Discussions 驱动，需 GitHub 账号。

**订阅地址会变吗？** 上方框内即为本站固定订阅地址，长期有效。
